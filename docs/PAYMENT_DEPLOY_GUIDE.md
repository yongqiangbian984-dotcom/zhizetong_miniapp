# 微信支付功能 - 部署指南

## 上传状态
✅ 小程序前端代码已通过 miniprogram-ci 上传成功 (V1.1.0)

## 待完成步骤

### 1. 云函数部署（重要）

由于云函数需要使用商户证书进行微信支付API调用，需要手动部署云函数：

#### 方式一：通过微信开发者工具部署
1. 打开微信开发者工具
2. 导入项目 `小程序课程平台`
3. 在 `cloudfunctions/api` 文件夹上右键
4. 选择「上传并部署：云端安装依赖」
5. 等待部署完成

#### 方式二：通过命令行部署
```bash
cd ./小程序课程平台/cloudfunctions/api
npm install
tcb fn deploy api --force
```

### 2. 微信支付回调配置

支付成功后需要配置回调地址接收微信通知：

1. 登录微信支付商户平台 (https://pay.weixin.qq.com)
2. 进入「产品中心」→「支付配置」→「JSAPI支付」
3. 设置「支付回调URL」为云函数的HTTP触发地址

**注意**：当前云函数配置了示例回调地址，需要替换为实际的云函数HTTP地址。

获取云函数HTTP地址：
```bash
tcb fn url api
```

### 3. 数据库集合确认

确保以下集合已存在：
- `orders` - 订单表
- `user_courses` - 用户课程表
- `commissions` - 佣金表

## 功能清单

### 已实现功能

1. **支付云函数API** (`cloudfunctions/api`)
   - `createPayment` - 创建支付订单
   - `paymentCallback` - 处理支付回调
   - `refundOrder` - 申请退款
   - 微信支付APIv2统一下单
   - 签名验证

2. **前端页面**
   - 支付确认页面 (`pages/pay/index`)
   - 订单列表页面 (`pages/order/list`)
   - 课程详情页购买按钮

3. **分销功能**
   - 三级分销佣金计算
   - 自动记录佣金到commissions集合

### 支付流程

1. 用户在课程详情页点击「立即购买」
2. 跳转到支付确认页面
3. 点击「立即支付」调用 `createPayment`
4. 云函数调用微信统一下单API
5. 返回支付参数，前端调用 `wx.requestPayment`
6. 用户完成支付
7. 微信服务器回调云函数
8. 云函数验证签名并更新订单状态
9. 添加用户课程记录
10. 计算并记录分销佣金

## 注意事项

1. **证书安全**：商户证书已Base64编码嵌入代码，生产环境建议使用环境变量或云存储
2. **回调URL**：需要配置真实的云函数HTTP地址
3. **签名密钥**：确保APIv2密钥配置正确
4. **域名白名单**：确保已配置微信支付合法域名

## 测试建议

1. 使用微信开发者工具的「模拟支付」功能测试
2. 配置商户平台为「沙箱模式」进行测试
3. 验证订单状态流转正确
4. 验证佣金计算正确

## 常见问题

Q: 统一下单失败？
A: 检查商户号、API密钥、证书是否配置正确

Q: 支付回调失败？
A: 检查云函数HTTP触发地址是否可公网访问

Q: 签名验证失败？
A: 确保使用正确的API密钥进行签名
